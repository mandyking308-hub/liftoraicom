# Montvelle Professional Advisory Network — Global Outreach Standard

## Purpose

Build a durable institutional advisory network that Montvelle can use to route complex private-client needs and develop relationships with globally recognised professional firms.

This is not a directory of local advisers. The default inclusion threshold is a recognised international institution with meaningful cross-border capability, a multi-market operating footprint, or exceptional global specialist standing.

## Selection rule

Prioritise:

1. Global private-client and international law firms
2. Big Four and major international tax/accounting networks
3. Global private banks and wealth managers
4. Global fiduciary, trust and corporate-services groups
5. International immigration, residency and global-mobility firms
6. Global property advisers
7. Global insurance and risk brokers
8. International security, intelligence and investigations firms
9. Major investment banks and independent M&A advisers
10. Global executive-search firms
11. Global reputation and crisis advisers
12. International private-health institutions
13. Major global auction houses and art advisers
14. Institutional philanthropy and family-governance advisers

Small local firms should normally be held outside the core network unless a later client case requires a jurisdiction-specific specialist.

## Contact-data rule

For each institution capture:

- organisation name
- category
- global tier
- website
- official enquiry/contact route
- published generic/business email where one is genuinely evidenced
- email source URL
- best-for client use cases
- geographic coverage
- outreach status
- relationship status
- last verification date

Never manufacture an email pattern. A website enquiry form or official contact page is a valid route when no public business inbox is published.

## Relationship rule

Database inclusion does not mean partnership, endorsement or approved-adviser status.

Relationship lifecycle:

`Prospect → Contacted → Active → Preferred → Held`

Outreach lifecycle:

`Not contacted → Queued → Sent → Replied → Follow-up → Closed`

## Montvelle operating principle

The client should not need to know which professional category they require. Montvelle starts with the client outcome, identifies the advisory combination required, and routes the request to the strongest suitable institutions in the network.
