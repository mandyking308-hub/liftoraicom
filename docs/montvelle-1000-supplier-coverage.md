# Montvelle — 1,000 Supplier Core Coverage

## Milestone

The first Montvelle sourcing core contains **1,000 supplier organisations**. It is designed as a concierge fulfilment asset rather than a public supplier directory.

Each organisation is retained separately from its operational route(s), outreach status and relationship status. Inclusion does not imply partnership, approval or endorsement.

## How Liftor should use the asset

For a live Montvelle request:

1. Determine service type, destination, date/time, party size and constraints.
2. Search the supplier registry by category and geography.
3. Prefer a verified direct operational route suitable for fulfilment.
4. If no direct route is available, use an official network route or supplier contact form.
5. Respect membership, trade, advisor, licensing or other access prerequisites.
6. Never promise access before the prerequisite is satisfied.
7. Record the outcome and retain any successful new route for future requests.

## Website rule

The public Montvelle site should communicate **capability and global sourcing reach**, not expose the internal 1,000-record directory. Supplier names can be used selectively as factual sourcing references; partnership/preferred-supplier language requires evidence of the relationship.

## Next phase

After the 1,000-supplier milestone:

1. design the public supplier/network credibility layer;
2. segment the 1,000 into outreach waves;
3. prioritise network multipliers and suppliers that can improve commercial terms or priority access;
4. send institutional supplier-introduction outreach;
5. convert replies into vetted/approved/preferred relationships while keeping live fulfilment routes operationally separate.
