How to read an entry:

- **Open at** — the module root route. Child routes are sub-tabs or detail views of it.
- **What you see** — the first heading rendered by the root page.
- **Controls** — button labels found in the root page source.
- **Internal writes** — whether any page in the family writes to Liftor's own database.
- **Provider reach** — the edge functions the family's pages can invoke. `none` means the family cannot reach any provider at all; it reads and writes Liftor's database only.

- **Empty / error states** — empty-state strings found in the root page source.
